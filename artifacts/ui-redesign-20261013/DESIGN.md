# Jacob Travel · 旅行工作台改版

用户明确授权大改现有 UI，主线程作为经理安排三个并行 Codex 任务，并统一真实浏览器验收、数据保护和 Git 提交。基线 `1a91cb4f6451280752f08d079d1fedc7713428b1` 已核对 GitHub QA 分支。原有十个生成脏文件和旧 untracked 单独快照保存。

## 参考与判断

- [Wanderlog 官方产品页](https://wanderlog.com/)：按日组织行程与地图，让旅行信息在同一工作区可达。主线程实际查看公开产品截图，不登录或导入私人数据。
- [TripIt 官方功能页](https://www.tripit.com/web/free)：订单资料、交通和导航依旅行情境聚合。
- [Airbnb 官方行程说明](https://www.airbnb.com/help/article/4192)：围绕一次旅行查看预订、日期与已保存地点。

本轮借鉴信息层级与清晰操作，不新增同步预订、自动路线优化或外部账号连接。照片、Jacob 头像和事实数据保留。

旧首页实际首屏大封面占据450px，待办入口落在下方；820px桌面实际时间线遮挡概览；手机概览需要横滑才能看完整；探索卡只有名称/价格，缺少已有描述、城市和加入目标。主按钮旧浅蓝配白字的对比度为2.46:1。手机执行页面缺少直接返回概览入口。

## 统一方向

系统 sans 字体、墨色文字、深蓝主按钮、柔和灰底和白色卡片。照片提供旅行感，标题与操作提供用途。主色 `#1f4b63`、hover `#163b50`，浅色只用于选中背景；保留语义状态色和清晰键盘焦点。

首页使用紧凑封面、真实旅行日期、所选Day入口和更早可见的待办；手机当天页面减少重复框并展示完整概览，探索宽卡提供已有简介与明确目标；桌面宽屏保留可调行程/概览/地图，窄屏通过明确切换显示行程，避免遮挡。全局导航显示中文，但 URL/ViewId 不变。
